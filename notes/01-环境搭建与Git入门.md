## 2. Git 基本工作流

```bash
git add <文件>        # 暂存修改
git commit -m "说明"  # 提交到本地仓库
git push              # 推送到远程仓库(GitHub)
git pull              # 拉取远程最新代码
```

核心流程：**工作区 → (add) → 暂存区 → (commit) → 本地仓库 → (push) → 远程仓库**
