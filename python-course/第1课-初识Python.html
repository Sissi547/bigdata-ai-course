概念一 · 7 分钟

print()：让电脑"开口说话"

print()
把括号里的内容显示在屏幕上。它是 Python 自带的"显示器喇叭"——你在键盘上敲，它在屏幕上喊。
print("快讯：本市今起开通 24 小时新闻热线") 快讯：本市今起开通 24 小时新闻热线
两个新手必看细节：① 文字必须放在引号里（单引号双引号都行，但要配对）；② 括号必须是英文括号，写成中文（）会直接报错——这是新手第一大坑。
概念二 · 8 分钟

变量：给内容起个名字

变量
像一个贴了标签的盒子：把内容放进去，以后喊标签就能取出来用。用 = 号把内容"装进盒子"（叫"赋值"）。
title = "暴雨突袭，三环多处积水" # 把标题装进名叫 title 的盒子 print(title) # 喊它的名字，屏幕上就会出现标题 暴雨突袭，三环多处积水

为什么要有变量？因为内容可以换：

title = "暴雨突袭，三环多处积水" print(title) title = "积水已退，交通恢复" # 同一个盒子，装了新内容 print(title)
变量命名规则 · 官方规定

给盒子起名的三条规矩

1. 用英文
Python 的官方习惯是用小写英文单词加下划线，如 news_title、reporter_name（官方术语表称 snake_case 风格）
2. 别用开头是数字
title1 合法，1title 非法——名字不能以数字开头
3. 避开关键字
print、if、for 这些是 Python 的"官方保留词"，不能拿来当名字，否则程序会"精神错乱"
好名字标准：半年后回看，不用解释也知道里面装的什么
概念三 · 5 分钟

注释：写给人看的"采访笔记"

# 注释
以 # 开头的行，电脑完全忽略，纯粹写给人看。相当于代码旁边的"编者按"。
# 下面这条快讯面向全城读者发布 title = "热线开通首日接到来电 200 通" print(title) # 打印标题
新闻行业讲"信源可查"，编程行业讲"注释清晰"——好的注释就是给未来的自己（和同事）留的信源。官方建议：注释要解释"为什么"，而不是重复"做了什么"。
跟练 · 15 分钟

动手：三条快讯，一段开场白

把下面的代码在 Python 里敲一遍（别复制，敲才有手感），改改内容再运行一次：

# 我的第一个新闻程序 station = "校园之声广播站" news1 = "运动会下周三开幕，报名截止本周五" news2 = "食堂三楼新开面档，人均 12 元" print("这里是" + station) # + 号可以把两段文字接起来 print(news1) print(news2)
练习 A

把 station 改成你自己社团的名字，运行看变化。

练习 B（思考题）

故意把 print 写成 Print 会怎样？——报错。Python 区分大小写，这行报错信息读作"Print 没有定义"。以后见到红色报错，先别慌，它其实在告诉你"哪里不对劲"。
