情感分析：
让程序判断一条标题是"喜"还是"忧"

这是你的第一个真正的 AI 应用：给它一段文字，它回你一个 0 到 1 之间的分数，越接近 1 越正面。你将知道它背后两种完全不同的做法。

为什么学 · 5 分钟

一千条标题，人手看不过来

月底复盘时，主编想知道：这个月我们的报道整体情绪是偏正面还是偏负面？哪几条标题最负面、需要检讨？

人工做法

一条条读、一条条感受，一千条要看几个小时，而且两个人标准还不一样。

程序做法

一个循环跑完，每条给出 0~1 的分数，几秒钟出结果，还能自动排序。

这就是情感分析的用途：把"读起来什么感觉"变成"一个可以排序的数字"。数字才好比较、好统计、好画图。
理论一 · 7 分钟

做法 A：词典法（查字典打分）

词典法
事先准备一份"褒义词 / 贬义词"词表，看句子里各出现几个，按比例算分。像老师批作文数好词好句。
"圆满落幕，掌声不断" → 褒义词 2 个，贬义词 0 个 → 分数高（正面） "暴雨突袭，多处积水" → 褒义词 0 个，贬义词 2 个 → 分数低（负面）
优点：简单、快、结果可解释（能告诉你为什么扣分）。
缺点：词表里没有的词就抓瞎；反话、否定句容易判错，比如"不是很满意"。
理论二 · 6 分钟

做法 B：机器学习法（从例子中学）

机器学习法
不查表，而是给模型看大量已经标注好的句子（这条是正面、那条是负面），让它自己总结规律。像带实习生看一千篇稿子，看多了自然有感觉。
训练阶段：喂入 10 万条已标注文本 → 模型自己找规律 预测阶段：给一条新标题 → 模型根据学到的规律给出分数
优点：能处理没见过的表达、更贴近真实语言。
缺点：需要标注数据；分数怎么来的不那么直观（"黑箱"感）。
课程用的 SnowNLP，属于"在标注语料上训练过的模型"，用起来像词典法一样简单
实操 · 20 分钟

动手：给 8 条标题打分并排名

from snownlp import SnowNLP titles = [ "暴雨突袭，三环多处积水，市民出行受阻", "校园歌手大赛圆满落幕，掌声不断", "图书馆延长开放时间，同学纷纷点赞", "食堂被曝使用过期食材，校方致歉", "运动会开幕式精彩纷呈", ] results = [] # 收结果：每条存成 (分数, 标题) for t in titles: try: score = SnowNLP(t).sentiments # 属性：读情感分（不带括号） results.append((score, t)) except Exception as e: print(f"跳过：{e}") results.sort() # 从小到大排：最负面的在前 print("— 最负面 3 条 —") for s, t in results[:3]: print(f"{s:.2f} {t}")
四个知识点全在这里：函数与模块（import）、列表与循环（第 3 课）、类与对象（读属性）、异常处理（try）。AI 应用就是基础语法的组合。
看结果 · 5 分钟

怎么读这个分数？

0.0 很负面
0.5 中性
1.0 很正面
三个必须知道的注意点：
① 分数只反映"用词倾向"，不等于新闻价值判断——负面新闻不等于坏新闻；
② 反话、否定句可能判错（"不是很满意"）；
③ 任何模型都有误差，人工复核永远必要——这是数据新闻的职业底线。
跟练 · 8 分钟

两个练习

练习 A｜做自己的榜单

把你最近看到的 10 条真实新闻标题放进去，跑出"最正面 / 最负面"各 3 条，看看机器判断和你的直觉是否一致。不一致的，想想是反话还是模型没学过的词。

练习 B｜平均值

算出这 10 条标题的平均分，作为"本月报道基调"的一个粗略指标。提示：用第 1 次课学的 statistics 模块，或把分数列表加起来除以条数。

写数据分析小结时，请照新闻规范注明：数据来源、样本量、工具与已知局限——这是你区别于"随便跑个模型"的地方。
