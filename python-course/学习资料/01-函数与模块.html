函数与模块：
把重复的动作打包成一个按钮

你已经会写代码了。但同样的统计动作写第三遍时，你会开始烦——函数就是为解决这种"烦"而生的。

为什么学 · 5 分钟

先看一段"很烦"的代码

你统计了三篇稿件的词频，代码是这样的：

text1 = "暴雨 积水 暴雨 交通" counts1 = {} for w in text1.split(): counts1[w] = counts1.get(w, 0) + 1 text2 = "开学 典礼 开学" counts2 = {} for w in text2.split(): counts2[w] = counts2.get(w, 0) + 1
一模一样的四行，抄了两遍（第三篇还要抄）。copy 得越多，改起来越容易漏——将来想改进算法，得改三个地方。函数就是为了消灭这种复制粘贴。
生活类比 · 3 分钟

函数 = 咖啡机上的一个按钮

没有函数

每次想喝咖啡，都要自己磨豆、烧水、过滤——步骤一样，但每次都得重来一遍。

有了函数

把整套流程装进机器，面板上只有一个"美式"按钮。想喝？按一下。流程被封装，动作被复用。

写一次，用无数次 —— 这就是函数

按钮还能"选口味"：按"拿铁"出来的是拿铁。函数也一样，可以带参数（放什么进去），还能给回结果（出来什么）。

核心一 · 7 分钟

def：定义一个函数

def
define（定义）的缩写。写法：def 函数名(参数): 然后缩进写流程。函数名取法和变量一样。
def greet(name): print(f"你好，{name}！") greet("王主编") # 这叫"调用"函数：按下按钮 greet("李记者") 你好，王主编！ 你好，李记者！
两个动作要分清：def 只是"造按钮"（造完不会自己运行）；调用才是"按按钮"（写上函数名加括号才执行）。忘了调用，屏幕上什么都不会出现——新手第一个困惑就是这个。
核心二 · 6 分钟

return：把结果"交出来"

return
把函数算出的结果交回给调用者，可以存进变量继续用。没有 return，函数就只是干完活就走。
def count_words(text): counts = {} for w in text.split(): counts[w] = counts.get(w, 0) + 1 return counts # 把统计结果交出去 result = count_words("暴雨 积水 暴雨") # 用变量接住 print(result) {'暴雨': 2, '积水': 1}
print 和 return 的区别：print 是"喊出来给人看"，return 是"递过来给你用"。想让结果能被后续代码处理，就必须 return。
核心三 · 5 分钟

模块：别人写好的工具箱

import
把 Python 自带的"工具箱"（模块）搬进来用。官方教程的说法：模块是包含函数与变量的文件，用 import 引入。
import statistics # 自带统计工具箱 views = [1200, 3400, 2800, 9100, 1500] print(statistics.mean(views)) 3600 print(statistics.median(views)) 2800
你不需要自己从零写"求平均数"——官方工具箱里早就有，一行 import 即可。站在别人肩膀上，是编程的正经做法，不是偷懒。课程后续用到的 snownlp、scikit-learn 也是这样引入的第三方模块。
跟练 · 18 分钟

动手：把热词统计器改造成函数

对照第 4 课写过的统计器，这次把它装进"按钮"里，再点三次：

# 把统计逻辑打包成函数 def count_words(text): counts = {} for w in text.split(): counts[w] = counts.get(w, 0) + 1 return counts # 三篇稿件，同一个函数处理三次 news = [ "暴雨 积水 暴雨 交通", "开学 典礼 开学 典礼 典礼", "运动会 报名 开幕", ] for n in news: # 复习第 3 课的 for 循环 print(count_words(n))
练习 A

加一个函数 top_word(counts)，让它返回出现次数最多的那个词。提示：用 max(counts, key=counts.get)。

练习 B

给 count_words 加第二个参数 min_count=1，只保留出现次数达到该值的词。

常见坑 · 3 分钟

新手最容易栽的四个地方

忘了调用
只写 def 不写 greet("王主编")，程序不会报错，也不会输出——因为按钮造好了但没人按。
忘了 return
函数里用 print 而不是 return，外面 result = count_words(...) 接到的是 None（空）。
缩进漏了
def 下面的流程必须缩进。不缩进的话，那几行就"跑出"函数之外了——Python 的缩进是语法，不是排版。
忘了括号
调用时写成 greet 只是"提到这个按钮"，greet() 才是"按下去"。差一对括号，结果差很远。
