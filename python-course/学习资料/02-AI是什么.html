为什么学 · 5 分钟

先看一个"写不完"的规则

主编让你给 1000 条标题判断"正面 / 负面"，你第一反应是写规则：

# 用 if 把规则一条条写死 def is_positive(title): if "喜" in title or "成功" in title: return "正面" elif "事故" in title or "下跌" in title: return "负面" return "说不准"
遇上"暴雨后市民自发清淤"：有"暴雨"，规则判负面，可这明明是好新闻。例外永远写不完——这就是需要机器学习的时刻。
生活类比 · 3 分钟

两种"审稿标准"的来源

规则法：像照着一本手册打分

新编辑先背《审稿手册》，手册上第几条怎么写就怎么判。手册没写到的稿子，他当场卡住。

机器学习：像看了一千篇稿的老师傅

没人给他手册，只给他 1000 篇已经标好"正面/负面"的稿子。看多了，他自己总结出一套眼力。

标准不是人写的，是从数据里"看"出来的

妙处在这儿：老师傅说得清结论，却说不清自己脑子里第几条规则。他"学到"的东西存在哪儿？存在"模型"里。

核心一 · 5 分钟

"写死规则"和"从数据学"差在哪

写死规则
人先想清楚"看到什么词就判什么"，再翻译成 if。电脑只负责执行。特征是人挑的，规则是人定的。
机器学习
人只准备两样东西：一批"标题"和一栏"正确答案"。规律由模型从这批数据里自己找出来。官方说法叫从数据中学习并做出预测。
# 做法一：规则由人写死 if "下跌" in title: label = "负面" # 做法二：规律从数据里学（不写规则，只喂数据） # 给它 1000 对「标题 → 正面/负面」，让它自己总结 data = [("校园招聘会提供 3000 个岗位", "正面"), ("暴雨致道路积水 交通中断", "负面")] # 这里的 data，专业名叫"训练数据"
上半场的函数是"人把步骤告诉电脑"；机器学习是"人把例子告诉电脑"。这一步思路的转变，就是整门课的分水岭。
核心二 · 6 分钟

三个必会的词：模型、训练、预测

模型
大白话：一台"看了很多例子后形成的判断机器"。你喂它一条新标题，它给你一个判断。类比：老师傅脑子里那套说不出口的眼力。
训练
大白话：让模型看例子、自己调自己的过程。给它"标题 + 正确答案"，它猜一次、对一次答案、改一次自己，重复很多轮。注意：规则依然是人写的，但规律是它自己找的。
预测
大白话：拿训好的模型去判断没见过的新数据。这一步你不用再给答案——给了就不用预测了。
# scikit-learn 里所有模型都是同一个"作息"（骨架示意） model.fit(标题列表, 正确答案列表) # 训练：从数据里学 model.predict(["新标题"]) # 预测：给新标题打标签 # 具体用哪个模型类，第 08 份资料里细讲
核心三 · 7 分钟

第一个实操：让"现成模型"给标题打分

好消息是：很多时候你不用自己训。别人训好的模型可以直接借来用，这叫预训练模型。

# 环境准备，只做一次。国内已配清华源，直接装即可： # pip install snownlp from snownlp import SnowNLP titles = ["学校食堂推出夜宵窗口 学生排队点赞", "暴雨致城区多条道路积水 交通一度中断"] for t in titles: score = SnowNLP(t).sentiments # 0~1 的"正面概率" print(round(score, 2), t) 0.96 学校食堂推出夜宵窗口 学生排队点赞 0.11 暴雨致城区多条道路积水 交通一度中断
分数不是"打了几颗星"。SnowNLP 官方说明：sentiments 返回的是这条文本属于正面的概率，越接近 1 越正面，越接近 0 越负面。（上面两条分数以你电脑上的实际输出为准。）
跟练 · 18 分钟

动手：给 5 条标题排个"情绪榜"

敲一遍，别复制——打字的过程就是在记语法。新建 ai01.py，把下面这段敲进去跑：

from snownlp import SnowNLP titles = [ "学校食堂推出夜宵窗口 学生排队点赞", "暴雨致城区多条道路积水 交通一度中断", "校园招聘会提供 3000 个岗位", "图书馆延长开放时间 考研学生叫好", "实验楼施工噪音扰民 学生投诉无果", ] results = [] # 空列表，准备装结果 for t in titles: score = SnowNLP(t).sentiments # 0~1 的正面概率 results.append((round(score, 2), t)) for score, t in sorted(results, reverse=True): print(score, t)
练习 A

打印时多说一句话：分数大于 0.6 加印"偏正面"，小于 0.4 加印"偏负面"，中间加印"模型也拿不准"。提示：用 if / elif / else。

练习 B

再用第 4 课的关键词规则法判一次同样的 5 条标题，把两种结果并排打印，数一数有几条不一致。

常见坑 · 3 分钟

新手最容易想歪的三个地方

以为一定准
SnowNLP 项目自带说明：它的情感模型主要用购物评价训练，用在新闻上效果不保证。"不准"是常态——学会看它错在哪，比抱怨它不准有用。
把训练想成玄学
训练不是程序员偷偷写规则，而是拿大量带正确答案的例子反复喂。所以数据里没有的东西，它学不到；数据偏了，它也跟着偏。
把 0.5 当零分
sentiments 是正面概率，不是百分制分数。0.5 附近表示模型拿不准；判正负通常看的是它离 0.5 有多远，而不是"够不够 60 分"。
