为什么学 · 5 分钟

你很快会遇到这样一行代码

from snownlp import SnowNLP s = SnowNLP("暴雨导致多条道路积水") # 注意这行的写法 print(s.sentiments)
两个陌生写法：SnowNLP("...") 长得像函数但不是；s.sentiments 后面不带括号。这就是类与对象——不明白它，你只能死记硬背别人的示例代码；明白了，你会知道哪部分能改成自己的内容。
生活类比 · 4 分钟

类 = 模具，对象 = 压出来的月饼

类（class）＝模具

"新闻稿"模具，规定了每篇稿子都该有标题、正文、字数这些属性，也该会"算字数"这个动作。模具本身不是稿子。

对象（object）＝具体那篇稿子

用模具压出来的一篇具体稿件，比如《暴雨突袭》。它有自己的标题和正文，也能执行"算字数"。

类定义"应该有什么"，对象是"具体的一个"

所以 SnowNLP("暴雨导致多条道路积水") 是在用模具压出一篇"待分析文本"，s.sentiments 就是读出它的情感分数。

核心一 · 8 分钟

最小的类：属性与方法

属性
对象身上带的数据，写作 对象.属性名（不带括号）。例：s.sentiments。
方法
对象身上带的动作/函数，写作 对象.方法名()（带括号）。例：s.keywords(3) 取前三个关键词。
class Draft: # 造一个"稿件"模具 def __init__(self, title): # 压模具时自动执行，用来装初始数据 self.title = title def word_count(self): # 方法：算标题字数 return len(self.title) d = Draft("暴雨突袭三环") # 压出一个具体对象 print(d.title) 暴雨突袭三环 print(d.word_count()) 6
这页不用背。你只需要记住那条铁律：后面带括号的是动作，不带括号的是资料——凭这个就能读懂绝大多数 AI 库的用法。
核心二 · 7 分钟

异常处理：给程序系上安全带

try / except
把"可能出事的操作"放进 try；万一真出事，不崩溃，改走 except 里的备用方案。
texts = ["暴雨导致积水", " ", "开学典礼举行"] for t in texts: try: score = analyze(t) # 可能因空白文本而报错 print(f"得分：{score:.2f}") except Exception as e: print(f"跳过一条：{e}") # 记录原因，继续下一条
处理真实新闻数据时，脏数据一定存在（空行、乱码、超长文本）。没有 try，一条脏数据就能让整个批处理停下来；有了它，程序会跳过问题、跑完全程。
跟练 · 12 分钟

动手：批量打分时不怕出错

先安装库（国内源已配好，一条命令即可）：

# 在命令行里执行（不是 Python 里） pip install snownlp
from snownlp import SnowNLP titles = [ "暴雨突袭，三环多处积水，市民出行受阻", " ", # 故意混入一条脏数据 "校园歌手大赛圆满落幕，观众掌声不断", ] for t in titles: try: s = SnowNLP(t) # 压出对象 print(f"{s.sentiments:.2f} {t[:12]}") # 读属性，保留两位小数 except Exception as e: print(f"跳过：{e}")
练习 A

把你自己的 5 条校园新闻标题加进去，看分数是否合理。

练习 B

试着把 s.sentiments 写成 s.sentiments()，看报错说什么——记住"属性不带括号"。

常见坑 · 3 分钟

三个高频翻车点

属性加括号
s.sentiments() 会报 TypeError（float 不可调用）。属性是资料，不是动作。
except 写太宽
except: 裸写会把所有错误都吞掉，包括你拼错变量名这种"真 bug"。建议写 except Exception as e: 并打印原因。
忘了缩进
try 里面和 except 里面都要缩进；两个块必须配对出现，不能只有 try。
