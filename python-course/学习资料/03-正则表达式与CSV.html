为什么学 · 5 分钟

不洗数据，统计就白做

你从群里复制了一条稿子，直接统计词频，结果是：

text = "暴雨突袭！城区积水，暴雨导致交通中断。详情见 https://news.example.com/a1" print(text.split()) ['暴雨突袭！城区积水，暴雨导致交通中断。详情见', 'https://news.example.com/a1']
"暴雨"明明出现两次，机器一次也没数对：它没有"词"的概念，只认空格。标点粘在词上、网址混在里面，统计结果就是一团乱麻。
生活类比 · 3 分钟

洗数据 = 做菜前的择菜、洗菜

不洗就下锅

带着泥、烂叶、草绳一起炒。菜是炒熟了，但你没法吃——统计也是一样，词算出来了，但算的是"暴雨突袭！城区积水，"。

先洗再下锅

择掉烂叶、冲掉泥沙、切掉根部，留下的都是能吃的部分。洗完之后，后面每一步都省心。

AI 的效果，一大半在这道"洗菜"工序上

所以行业里有句老话：垃圾进，垃圾出。数据没洗干净，再好的模型也白搭。

核心一 · 6 分钟

re.sub：按"模式"把杂质换掉

正则表达式
大白话：一个"描述文字长相"的模板。官方教程 5.7 节的说法是"用来匹配字符串的简单工具"。比如"\d"表示一个数字，\S+ 表示一串没空格的字符。
re.sub
sub 是 substitute（替换）的缩写。写法：re.sub(模式串, 换成什么, 原字符串)。把匹配到的部分换掉，变成"什么都没有"就直接写空字符串 ""，等于删除。
import re text = "暴雨突袭！城区积水，详情见 https://news.example.com/a1 。" clean = re.sub(r"https?://\S+", "", text) # 删掉网址 clean = re.sub(r"[，。！？、；：（）《》]", "", clean) # 删掉中文标点 print(clean) 暴雨突袭城区积水详情见 print(text) 暴雨突袭！城区积水，详情见 https://news.example.com/a1 。
注意最后两行：re.sub 不修改原字符串，它返回一个新字符串。所以必须写 clean = re.sub(...)，光写一行 re.sub 是白洗的。
核心二 · 6 分钟

re.findall：把符合长相的都捞出来

re.findall
find all（找出全部）。写法：re.findall(模式串, 原字符串)，返回一个列表，里面是所有匹配到的字符串。上面用完 sub 去杂质，这里负责把有用的捞出来。
text = "暴雨突袭，城区积水。暴雨导致交通中断，市民出行受阻。" # [\u4e00-\u9fa5] 表示一个汉字，{2,} 表示连续 2 个及以上 words = re.findall(r"[\u4e00-\u9fa5]{2,}", text) print(words) ['暴雨突袭', '城区积水', '暴雨导致交通中断', '市民出行受阻']
sub 是"改"，findall 是"找"——这是新手最容易混的一对。只想去掉杂质，用 sub；想拿到一个列表，用 findall。（更细的中文分词，等第 06 份资料用 SnowNLP 来做。）
核心三 · 6 分钟

csv：把结果存成表格文件

import csv
Python 自带的表格工具箱，官方教程 7.2 节。csv.reader 一行行读（每行是个列表），csv.writer 一行行写。不用装任何东西。
import csv rows = [["词", "次数"], ["暴雨", 2], ["积水", 1]] # 写：中文文件一定写 encoding="utf-8"，否则打开是乱码 with open("词频.csv", "w", encoding="utf-8", newline="") as f: writer = csv.writer(f) writer.writerows(rows) # 读：同样要写 encoding="utf-8" with open("词频.csv", encoding="utf-8") as f: for row in csv.reader(f): print(row) ['词', '次数'] ['暴雨', '2']
为什么写文件要加 newline=""？官方教程 7.2 节专门提醒过：不加的话，Windows 上写出来的 CSV 每行之间会多一个空行。
跟练 · 18 分钟

动手：把一段带网址的稿子洗成干净词表

敲一遍，别复制。新建 clean01.py，边敲边看每一步 print 的变化：

import re import csv raw = """校运会开幕！3000 名学生参加，详见 https://news.example.com/s1。 本次校运会新增了夜间比赛项目，报名人数比去年增长两成。""" clean = re.sub(r"https?://\S+", "", raw) # 1 去网址 clean = re.sub(r"[，。！？、；：（）《》\n]", " ", clean) # 2 标点换成空格 clean = re.sub(r"\s+", " ", clean).strip() # 3 多余空格压成一个 print(clean) words = clean.split() # 4 切成词表 print(len(words), words) with open("干净词表.csv", "w", encoding="utf-8", newline="") as f: writer = csv.writer(f) writer.writerow(["序号", "词"]) for i, w in enumerate(words, 1): writer.writerow([i, w]) print("已写出 干净词表.csv")
练习 A

在第 2 步删掉数字，让"3000"不再出现在词表里。提示：用 re.sub 把 r"\d+" 换成空格。

练习 B

把第 2 步改成用 re.findall 只捞连续 2 个以上的汉字，比较两种结果有什么不同。

常见坑 · 3 分钟

新手最容易栽的三个地方

洗了等于没洗
写了 re.sub(...) 却没接住返回值。原字符串不会变，你得写 clean = re.sub(...)，再用 clean 做后面的处理。
模式串忘写 r
反斜杠会被 Python 先当字符串处理一遍。写成 r"\d+"（字符串前加 r）表示"原样交给正则"，官方教程的示例也都这么写。
打开是乱码
读写中文文件必须写 encoding="utf-8"。如果写出的 CSV 要用 Excel 直接双击打开、中文还是乱码，把编码改成 utf-8-sig 试试。
