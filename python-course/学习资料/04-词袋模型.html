词袋模型：
把一句话拆开，数一数每个词出现几次

上半场你洗出了干净词表，但词表还是一堆汉字。这一场我们把它变成数字表格——那是模型唯一看得懂的输入。

为什么学 · 5 分钟

模型看文字，就像你看一串乱码

上一次课，你信心满满地把三条标题喂给模型：

标题 1：暴雨导致交通中断 标题 2：校运会开幕 # 结果报错：模型期望的输入是"数字"，收到的是"字符串" # 它不认识"暴雨"这两个字，它只会算数字
这和你的处境很像：给你一篇稿子让你判断情绪，你一眼就看懂；给你一串 [0, 2, 0, 1, 0]，你完全不知道在说什么。想让机器帮你读新闻，就得先把新闻翻译成它的语言。
生活类比 · 3 分钟

词袋 = 把一袋糖按口味数一遍

倒进袋子

把整篇稿子的词全倒进一个袋子：暴雨、积水、暴雨、停课……不排队、不编号，先混在一起。

按口味点数

然后只做一件事：数每种口味有几颗——暴雨 2 颗、积水 1 颗、停课 1 颗。写下来就是一张表。

词袋只看"出现了几次"，不看"排在第几个"

少了一个词就记 0。于是每一篇稿件，都会变成一排数字——这一排数字，就是它有资格递给模型的"入场券"。

核心一 · 5 分钟

词袋的三个动作：拆词、数数、排成排

拆词
把句子切成一个个词。英文靠空格，中文没空格，得先"分词"——上半场你已经用 re.findall 捞过 2 字以上的词，第 06 份资料会教你用 SnowNLP 分得更准。
词表
把所有稿件里出现过的词收集起来、去重、排个序，形成一张"一共有哪些词"的清单。这张清单就是数字表格的列名。
数字表格
每一行是一篇稿件，每一列是词表里的一个词，格子里填这个词在这篇里出现了几次。这一排数字，专业名叫向量。
词表： ['暴雨', '积水', '停课', '校运会', '开幕'] 稿件1： [ 2, 1, 0, 0, 0 ] # 暴雨 积水 暴雨 稿件2： [ 1, 0, 1, 0, 0 ] # 暴雨 停课 稿件3： [ 0, 0, 0, 2, 1 ] # 校运会 开幕 校运会
核心二 · 6 分钟

手工做一遍：字典就是那只袋子

用字典数
第 4 课你已经写过：counts[w] = counts.get(w, 0) + 1。现在你知道了，那四行代码干的就是"词袋"这件事。
docs = ["暴雨 积水 暴雨", "暴雨 停课", "校运会 开幕 校运会"] total = {} # 字典 = 那只袋子 for doc in docs: for w in doc.split(): total[w] = total.get(w, 0) + 1 print(total) {'暴雨': 3, '积水': 1, '停课': 1, '校运会': 2, '开幕': 1} # 词表：把袋子里的标签去重排序，当作表格的列名 vocab = sorted(total) print(vocab) ['停课', '开幕', '暴雨', '校运会', '积水']
注意上面这个 total 是三篇加起来的总数；表格要的是每一篇各自的数字，所以下一段我们按篇数一遍。（列的顺序由程序排序决定，不用背。）
核心三 · 6 分钟

工具箱版：一行 fit，全自动

CountVectorizer
scikit-learn 里专门做词袋的工具，官方文档「文本特征提取」章节的第一个示例。你把一段段文本交给它，它自动完成"拆词 → 建词表 → 数数 → 排成表格"。
from sklearn.feature_extraction.text import CountVectorizer docs = ["暴雨 积水 暴雨", "暴雨 停课", "校运会 开幕 校运会"] vectorizer = CountVectorizer() X = vectorizer.fit_transform(docs) # 学词表 + 转数字，一步到位 print(vectorizer.get_feature_names_out()) # 列名（词表） print(X.toarray()) # 数字表格，变成普通数组看 ['停课' '开幕' '暴雨' '校运会' '积水'] [[0 0 2 0 1] [1 0 1 0 0] [0 1 0 2 0]]
跟你手工算的那张表一模一样吧？工具箱没有魔法，它只是把你写过的循环打包了——官方文档里也特别提到：如果文本已经提前分好词，用空格隔开就好。
跟练 · 18 分钟

动手：三篇稿件，一张数字表格

敲一遍，别复制。新建 bow01.py，先不装任何库，纯 Python 走一遍全过程：

from collections import Counter docs = ["暴雨 积水 暴雨", "暴雨 停课", "校运会 开幕 校运会"] # 第 1 步：收集所有出现过的词，排序成词表 vocab = sorted({w for doc in docs for w in doc.split()}) print("词表：", vocab) # 第 2 步：每篇稿件按词表数一遍，变成一排数字 for doc in docs: counter = Counter(doc.split()) # Counter 直接替你数好 row = [counter.get(w, 0) for w in vocab] print(doc, "->", row)
练习 A

往 docs 里再加一篇"暴雨 停课 暴雨"，重跑一次，看看表格多出来的那一行长什么样。

练习 B

把三篇的 Counter 用 + 加成一个总的（Counter 支持相加），找出整个语料里出现最多的词。提示：回到概念 01 的 max(counts, key=counts.get)。

常见坑 · 3 分钟

词袋最容易踩的三个坑

以为它懂意思
词袋只数次数，不问顺序。"人咬狗"和"狗咬人"在它眼里完全一样；"不太满意"和"不，太满意了"也分不出。这是它的先天短板。
中文直接扔进去
官方文档写明：默认配置提取至少 2 个字母的词，中文单字（比如"雨"）会被悄悄丢掉。正确做法是先分词、再用空格连起来，或像文档 Tips 那样传 analyzer=str.split。
新词凭空消失
官方文档明确：训练语料里没出现过的词，在之后 transform 时被完全忽略（那一行数字会全是 0）。词表在 fit 那一刻就定死了。
