为什么学 · 3 分钟

先看"笨办法"有多啰嗦

想从标题列表里挑出所有长度超过 8 个字的标题，笨办法是：

long_titles = [] # 先准备空列表 for t in titles: if len(t) > 8: long_titles.append(t) # 一条条往里塞
功能没错，但 4 行只干了一件事。推导式把同样的事写成 1 行，而且读起来就像一句话："把长的那些标题挑出来。"
核心一 · 8 分钟

列表推导式：一行搞定筛选与变换

推导式
写法 [表达式 for 变量 in 列表 if 条件]，读作"对每个变量，满足条件就取这个表达式，组成新列表"。
titles = ["暴雨突袭三环积水", "开学典礼", "图书馆延长开放通知"] # 筛选：只留长度 6 以上的 long_titles = [t for t in titles if len(t) >= 6] print(long_titles) ['暴雨突袭三环积水', '图书馆延长开放通知'] # 变换：给每条加前缀 tagged = [f"【快讯】{t}" for t in titles] print(tagged[0]) 【快讯】暴雨突袭三环积水
先会读："对 titles 里的每个 t，满足 len(t)>=6 才留下"。读得懂就不会写错；写不出来时，先写笨办法再改造成推导式。
核心二 · 7 分钟

sorted：把排行榜排出来

sorted()
对列表排序，返回新列表（原列表不变）。关键武器是 key 和 reverse 两个参数。
# 字典：词 → 次数（第 4 课的热词统计结果） counts = {"暴雨": 3, "开学": 5, "食堂": 2} # 按"次数"从多到少排 for word, num in sorted(counts.items(), key=lambda x: x[1], reverse=True): print(word, num) 开学 5 暴雨 3 食堂 2
counts.items() 把字典变成"标签-数值"对的列表；key=lambda x: x[1] 意思是"按第 2 个元素（即次数）排"；reverse=True 是从大到小。这三块拼起来就是新闻热词榜。
核心三 · 6 分钟

Counter：数东西的专用工具

Counter
来自 collections 模块的计数器。一行就能完成第 4 课写了 6 行的词频统计。
from collections import Counter words = "暴雨 积水 暴雨 交通 暴雨 开学".split() c = Counter(words) # 一行完成统计 print(c.most_common(2)) # 直接取出现最多的前两名 [('暴雨', 3), ('积水', 1)]
对比第 4 课那个手写的 if/else 计数循环：功能一样，写法差 5 倍。标准库里有的，就别自己造——这是编程的基本经济学。
跟练 · 16 分钟

动手：热词榜升级版（三件套合体）

from collections import Counter text = "暴雨 积水 暴雨 交通 积水 暴雨 开学 典礼" words = text.split() c = Counter(words) # ① 一行统计 top = c.most_common(3) # ② 直接取前三 # ③ 推导式：只保留出现 2 次以上的词 hot = [w for w, n in top if n >= 2] print("— 热词榜 —") for i, w in enumerate(hot, start=1): # enumerate 顺带编号 print(f"{i}. {w}（{c[w]} 次）")
练习 A

把词换成你最近写的 10 条标题（用空格分隔），生成你自己的热词榜。

练习 B

给榜单加一个"只看长度 ≥ 2 的字词"（排除"的""了"），提示：在推导式的条件里加 and len(w) >= 2。

常见坑 · 3 分钟

三个容易写错的地方

推导式写太长
一行里塞三四个条件就没法读了。超过一层筛选，就退回普通 for 循环——可读性优先于短。
sorted 忘了 items
直接对字典排序只能排"标签"，得到的是字母顺序。要按次数排必须写 counts.items()。
Counter 忘了导入
它不在内置函数里，必须先 from collections import Counter，否则报 NameError。
