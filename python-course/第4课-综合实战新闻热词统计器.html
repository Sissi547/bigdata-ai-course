导入 · 5 分钟

数据新闻，从"数词"开始

记者的手工会读稿，程序的眼睛会数词。把一个月的本地新闻丢给程序，数出"暴雨""热线""涨价"各出现多少次——哪个词越来越热，选题就在那里。

要读的原料

要用的零件

for 循环 + if 判断 + 字典计数

要出的成品

每个词出现的次数排行榜

今天的新零件只有三个：读文件、拆词语、看懂报错。其余全是学过的。
新零件一 · 5 分钟

open()：把 .txt 文件读进来

with open("news.txt", "r", encoding="utf-8") as f: text = f.read() # 把整个文件内容读成一个字符串 print(len(text)) # 看看读了多少个字
读作："打开 news.txt 当作 f，用完自动关门"。三个参数记住：文件名；"r" 表示读（read）；encoding="utf-8" 保证中文不乱码（写中文内容必加，官方文档推荐的通用编码）。
新零件二 · 5 分钟

split()：把一句话拆成一串词

title = "热线 开通 首日 来电 200 通" words = title.split() # 按空格切分，得到一个列表 print(words) ['热线', '开通', '首日', '来电', '200', '通']
split() 括号里不写东西时，默认按空格切。它把"一篇文章"变成"词语列表"——列表是第 3 课的老朋友，for 循环马上就能派上用场。
新零件三 · 5 分钟

报错不可怕：学会读"案发通知"

print(news_title) Traceback (most recent call last): NameError: name 'news_title' is not defined
Traceback

"案发经过回放"：从下往上读

错误类型

NameError=名字不存在；TypeError=类型用错；SyntaxError=拼写/标点错

最后一行

= 结案陈词，直接说哪里错

官方教程专门有一章《错误与异常》——报错不是"你不行"，是 Python 在给你发采访线索：顺着最后一行去案发现场看看。
组装 · 15 分钟

完整作品：新闻热词统计器（30 行）

# news.txt 里是若干行新闻标题（词之间用空格隔开） counts = {} # 空字典：词 → 次数 with open("news.txt", "r", encoding="utf-8") as f: for line in f: # 逐行读文件 words = line.split() # 拆成本行词语列表 for w in words: # 逐个词检查 if w in counts: # 字典里有这个标签吗？ counts[w] = counts[w] + 1 # 有 → 次数加一 else: # 没有 → 新词条，从 1 起 counts[w] = 1 for word, num in counts.items(): # 逐个公布结果 if num >= 2: # 只报出现 2 次以上的热词 print(f"{word}：出现 {num} 次")
每一行你都在前三课见过：with open（今天）、for（第 3 课）、if/else（第 3 课）、字典取标签加一（第 3 课）、f-string（第 2 课）。程序就是把学过的小零件拼起来。作业：准备自己的 news.txt（10 行标题），跑出你自己的热词榜。
