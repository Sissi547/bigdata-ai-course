# 父母职业关联分析报告

**数据**：`E:\类别变量练习数据.csv`（GBK 编码，53 行 × 2 列）
**有效样本**：52 对（母亲工作缺失 1 条，已剔除）
**分析工具**：Python 3.12.10 / pandas / SciPy / seaborn
**日期**：2026-11-12

---

## 一、数据清洗与转化

| 问题 | 处理方式 |
|------|----------|
| 单元格内换行符（如“市经济合作局\n”） | 去除 `\n` 并 `strip()` 首尾空格 |
| 母亲工作缺失 1 条 | 类别标为“缺失”，不进入检验 |
| 原字段是单位名称（48/43 个唯一值） | 按关键词归类为职业类别 |
| “家庭父亲 / 家庭父母 / 无” | 统一归为“家庭主妇/无业” |
| 6 类过于稀疏（52 个样本） | 合并为 4 类：体制内 / 民营 / 个体 / 无业 |

**归类口径**

- **体制内** ＝ 党政机关 + 事业单位 + 国有企业
- **民营** ＝ 有限公司、有限责任公司等私营企业
- **个体** ＝ 个体户、店面、饭馆、菜市场摊位等
- **无业** ＝ 家庭主妇 / 家庭父母 / 家庭父亲 / 无

**归类结果分布**

| 类别 | 父亲 | 母亲 |
|------|------|------|
| 党政机关 | 21 | 14 |
| 事业单位 | 3 | 9 |
| 国有企业 | 5 | 3 |
| 民营企业 | 11 | 7 |
| 个体经营 | 10 | 7 |
| 家庭主妇/无业 | 3 | 12 |
| 缺失 | 0 | 1 |
| **合计** | **53** | **53** |

## 三、统计检验

| 指标 | 结果 | 解读 |
|------|------|------|
| 卡方检验 | χ² = 24.03，df = 9，**p = 0.0043** | 拒绝独立假设，存在显著关联 |
| 置换检验（10000 次） | **p ≈ 0.0045** | 小样本下结论稳健 |
| Cramér's V | **0.392** | 中等强度关联（0.3~0.5 为中等） |
| 同类别比例 | **55.8%**（29/52） | 独立假设下期望仅 34.4% |

> 说明：16 个格子中有 13 个期望频数 < 5，严格说不满足卡方近似条件，因此补做了不依赖大样本近似的置换检验，两者结论一致。

---

## 四、关联体现在哪里

1. **体制内“门当户对”最明显**：父亲在体制内的 29 人里，21 人（72%）配偶也在体制内，远高于独立时的约 50%。
2. **民营家庭多“一方主内”**：父亲民营的 11 人中，5 人（45%）母亲为无业/家庭主妇。
3. **个体户倾向同行结合**：父亲个体的 9 人中，4 人（44%）配偶也是个体经营；还有两对夫妻从事**同一店铺**（“北京路九洋菜市场刘伟鲜面店”“娟红杂粮食府”）。
4. **无业父亲样本仅 3 例**，比例 67% 看似很高，但样本太小，不宜下结论。

---

## 五、结论

> **在本次样本中，父母的职业类别之间存在统计显著的中等强度关联（p ≈ 0.004，Cramér's V ≈ 0.39），主要表现为“体制内—体制内”的高度聚集，以及民营家庭中母亲无业比例偏高。**

---

## 六、局限与注意事项

1. **样本小且非随机**：仅 52 对有效样本，属于便利样本（大概率来自同一批学生家庭），不能推广到总体。
2. **归类存在误差**：职业类别由单位名称关键词推断，“银光聚银化工”按国企处理、街道社区按党政机关处理等，均有讨论空间；不同归类会轻微改变数字。
3. **关联不等于因果**：数据无法排除地域、教育水平、户籍、年龄等混杂因素。
4. **小样本效应量不稳定**：Cramér's V 的置信区间较宽，换一批样本可能明显变化。
