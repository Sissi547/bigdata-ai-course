概念一 · 8 分钟

列表：一个盒子装一串东西

列表 list
用方括号 [ ] 把一串内容按顺序装在一起，用逗号隔开。官方教程说它是"最常用的数据结构"。
titles = ["运动会开幕", "食堂新面档", "图书馆延长开放"] print(titles[0]) # 按序号取，注意：序号从 0 开始！ 运动会开幕 print(len(titles)) # len() 数一共有几条 3
最重要的细节：序号从 0 开始——第 1 条是 titles[0]，第 2 条是 titles[1]。全世界新手都在这里栽过跟头，你现在栽过一次就等于免疫了。
概念二 · 7 分钟

if：让程序学会"判断"

if 判断
如果条件成立（True）就执行下面缩进的代码，否则跳过。相当于编辑对稿子说："符合标准就发，不符合毙掉。"
views = 5000 if views > 1000: print("头条候选！") 头条候选！
两个要点：① 条件后面有个冒号 :；② 下面要执行的行必须缩进 4 个空格——缩进不是排版喜好，是 Python 的语法本身。判断符号：> 大于、< 小于、== 等于（两个等号！一个等号是赋值）。
概念三 · 8 分钟

for：让电脑"逐条过稿"

for 循环
对列表里的每一项，各执行一次缩进里的代码。"for x in 列表" 读作："对列表里的每个 x"。
for t in titles: print(f"待编：{t}") 待编：运动会开幕 待编：食堂新面档 待编：图书馆延长开放
对比一下：没有循环，100 条标题要写 100 行 print；有了循环，3 行代码处理任意多条。这就是"会编程的人"和"人肉处理"的差距。
合体 · 6 分钟

if + for：筛选器诞生

titles = ["运动会开幕", "突发：教学楼消防演习", "食堂新面档", "突发：临时停水通知"] for t in titles: # 逐条过 if "突发" in t: # 含"突发"二字吗？in 也能查"在不在里面" print(f"🔴 加急：{t}") 🔴 加急：突发：教学楼消防演习 🔴 加急：突发：临时停水通知
4 行代码，从一串标题里自动挑出加急稿件——这就是第 1 课说的"重复的事交给程序"。下一个问题：能不能顺便统计每种词出现了几次？这就需要一个新盒子。
概念四 · 6 分钟

字典：自带"标签"的收纳柜

字典 dict
用花括号 { } 装"标签: 内容"对儿。不看序号，看标签取物。
word_count = {"暴雨": 3, "开学": 5} print(word_count["开学"]) 5 word_count[" hotline"] = word_count["hotline"] + 1 # 标签在就 +1
词典结构 + 循环 + 判断 = 词频统计。第 4 课我们将把这三样合起来，写出你第一个真正的数据新闻小工具。本课先记住：字典用标签存数，能"查"也能"加"。
跟练 · 8 分钟

动手：突发新闻筛选器 + 计数

titles = ["突发：教学楼消防演习", "运动会开幕", "突发：临时停水", "社团招新"] total = 0 # 计数器清零 for t in titles: if "突发" in t: total = total + 1 # 每发现一条，计数器 +1 print(t) print(f"共发现 {total} 条突发新闻")

练习：往 titles 里再加 3 条自己的标题（其中 1 条含"突发"），预测输出几条、计数是多少，再运行验证。先猜后跑是程序员最重要的练习方式。
