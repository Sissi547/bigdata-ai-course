概念一 · 6 分钟

两种最重要的"数据类型"

字符串 str
文字。必须套引号。名字是 string 的缩写——一串字符。
整数 int
不带小数点的数。不加引号。integer 的缩写。
headline = "开学典礼明日举行" # 文字 → 引号 + str pageviews = 5023 # 数字 → 不加引号 + int print(pageviews + 1) 5024
引号是两种类型的分界线："5023" 是文字（不能做加法算术），5023 才是数。类型搞混，是新手报错排行榜第一名。
数字的算术 · 5 分钟

Python 是个不要工资的计算器

print(8 + 2) 10 print(8 - 2) 6 print(8 * 2) 16 print(8 / 2) 4.0 # 注意：除法结果带小数点
新闻场景：月发稿 24 篇，平均每周几篇？print(24 / 4) → 6.0。加、减、乘、除四个符号：+ - * /，其中乘号是星号 *，除号是斜杠 /——键盘上都能找到。
概念二 · 7 分钟

f-string：让文字和数字"组装成句"

f-string
在引号前面加个 f，然后在句子里挖花括号槽位 { }，运行时把变量的值填进去。f 是 format（格式化）的缩写。
name = "王老师" time = "本周四下午两点" invite = f"邀请{name}于{time}接受采访" print(invite) 邀请王老师于本周四下午两点接受采访
没有 f-string 之前，拼句子要用很多加号，又长又容易错。官方教程明确推荐用 f-string 处理这类场景——改一个变量，整句话自动更新，这正是"程序"的意义。
概念三 · 6 分钟

input()：让读稿的人"说话"

input()
程序运行到这一行会停下来等你打字，你输入什么，它就把什么装进变量。括号里放一句提示语。
name = input("受访者姓名：") topic = input("采访主题：") print(f"已登记：{name}，主题「{topic}」")
新手第二大坑：input() 收到的一切都是文字（str）。哪怕你输入 2026，它也是文字 "2026"。想做算术，要先"转换类型"：int(input(...))——给文字脱掉引号外套。
跟练 · 17 分钟

动手：一封会自动变的采访邀请函

# 自动邀请函生成器 name = input("受访者姓名：") topic = input("采访主题：") duration = int(input("预计时长（分钟）：")) print("──────── 采访邀请函 ────────") print(f"尊敬的{name}老师：") print(f"我们希望就「{topic}」进行约{duration}分钟的采访。") print(f"折算下来约{duration / 60}小时，期待您的回复！")
练习 A

运行三遍，输入三个不同的人名，观察邀请函如何自动变化。

练习 B（思考题）

输入时长 90，最后一行输出"约1.5小时"。如果把 duration / 60 改成文字拼接会怎样？——试着自己拆解这个报错。
