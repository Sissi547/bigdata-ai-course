Agent 智能体入门

还是那个 AI 助手"小智"。这一次，我们不给它写卡片，而是让它自己接一个大活儿——顺便搞懂什么是 Agent。

一个故事 三组对比 四大部件 5 道小题

内容依据 Anthropic《Building Effective Agents》与 IBM《AI Agents》· 方向键翻页

故事开始

"帮我筹备读书会"——没有步骤的活儿

我
小智，帮我筹备下周的班级读书会。
智
好。读书会要定书目、订教室、发通知、出讨论题。教室有截止日期，我先订教室——查课表找空教室……订好了。书目我查了上次记录，不重复……通知草稿给你过目。
我
（这次我没给任何步骤，它自己拆任务、自己挑工具、干一步看一眼。）
能做到这一点的系统，就叫 Agent（智能体）
权威定义

三句话说清 Agent

来源说法大白话
IBM利用可用工具、自主设计工作流来执行任务的系统自己想办法干活的 AI
Anthropic在循环中根据反馈来使用工具的大语言模型干一步→看结果→再干下一步
OpenAI能代表你独立完成任务的系统你给目标，它给结果
三个来源说法不同，但共同的三个词：自主、工具、完成任务。
第一组对比

Agent vs 普通 AI 聊天

普通 AI 聊天Agent 模式
你给它的一句话，它回一句话一个目标，它交回结果
它的动作只动嘴动嘴 + 动手（查、算、订、发）
谁驱动每一步都等你说话自己推进，卡住才问你
记忆聊完就忘有记忆，接着上次进度干
出错错就错了能自己发现并改
IBM 的总结：聊天机器人是"陪你聊"，Agent 是"替你干"。
第二组对比

Agent vs 自动群发程序

自动程序 = 过山车

学校的自动群发短信：轨道（流程）事先铺死，一步步按预定的路走。步骤是人写死的——这不叫 Agent。

Agent = 骑车送信的快递员

只知道目的地，路线自己看着定：这条路堵了就换一条。步骤是它现场自己定的。

步骤人事先定死的 = 自动化
步骤 AI 现场自己定的 = Agent
它靠什么干活

Agent 的身体：四大部件

🧠 大脑

模型，负责想：先订教室还是先定书目

🛠 手脚

工具，负责做：查课表、发通知、搜资料

📔 记忆

存下干过的事：上次读过《三体》，这次不重复

📖 说明书

指令，管行为：发通知前先给我过目

干活的方式就是一个圈：想一步 → 做出来 → 看结果 → 不对就改 → 再做……像第一次做饭：尝一口，淡了加盐，再尝，直到能吃。
什么时候用它

Agent 不是万能的

✓ 适合交给 Agent

步骤没法提前预测的开放任务（筹备读书会要几步？没人知道）；需要边干边看反馈随时调整的事；量大到人盯不过来的事。

✗ 不适合交给 Agent

步骤固定、要结果每次一模一样的事（用普通自动化：更快更便宜更稳）；犯错代价极大又没法验证的事。

Anthropic 的核心建议（意译）：先找最简单的可行方案，实在不够用，再上 Agent——甚至可能根本不需要 Agent。
串一串

和前两课的关系

🧠 大模型 ＝ 聪明的脑子
🧑‍💻 Agent ＝ 脑子 + 手脚 + 记忆，能自己接活儿的"人"
📔 Skill ＝ 它口袋里的岗位手册（活儿有固定做法就掏卡照做）

"整理笔记"步骤固定 → 一张技能卡就够；"筹备读书会"步骤不定 → 才轮到 Agent 自由发挥。该用卡用卡，该自主自主。
