AI 通识 · 第一讲

Agent Skill：
给 AI 装上"技能包"

AI 很聪明，但聪明不等于熟练。这一讲，我们看看如何把"做事的方法"教给 AI，让它从"什么都懂一点"变成"这件事特别会做"。

是什么 怎么工作 有什么用 课后练习

适用对象：零基础学生 · 预计 20 分钟 · 方向键可翻页

从一个故事开始

聪明的实习生，缺一本手册

想象你招了一位名校毕业的实习生：智商很高，学什么都快。但第一天让他报销一张发票，他愣住了——流程是什么？表格在哪？找谁签字？

问题不在"不够聪明"，而在"不熟悉这件事的做法"。
没有手册的实习生

每次都要你从头教：先这样、再那样、小心别错……教完下个月又忘。

拿到岗位手册的实习生

翻开手册照着做，步骤不遗漏、格式不走样，你只需要看结果。

Agent Skill，就是写给 AI 的那本"岗位手册"。

定义

Skill 是什么？

Agent Skill（智能体技能）：把完成某类任务所需的方法说明、知识和工具用法，打包成一个 AI 可以"按需翻开"的能力模块。

像手机 App

装一个"翻译 App"，手机就会翻译；装一个"做课件的 skill"，AI 就会做课件。

像菜谱

同一口锅、同一个厨师，照不同菜谱就能做出不同的菜。

像 SOP 手册

把老员工的流程经验写成文档，新人照做就不出错。

拆开看看

一个 Skill 里面有什么？

最常见的形式是一个说明文档（如 SKILL.md），加上一些配套资源。

1
名字与描述（什么时候用我）

如"git 课件发布技能：当用户要发布网页课件时使用"。AI 靠这段描述决定是否加载它。

2
操作步骤（怎么做）

分步写清流程：先检查什么、再执行什么、出错怎么办。

3
配套资源（用什么做）

模板、示例、脚本等。比如做课件的 skill 里，可以带一份标准课件模板。

运行机制

AI 如何使用一个 Skill？

①
你提出任务

"帮我把这份笔记做成网页课件发布出去。"

②
AI 浏览技能目录

先只读每个 skill 的一句话描述，像看菜单，不逐本翻书——省时省力。

③
匹配到就"翻开"加载

发现"课件发布技能"的描述对上了，才读取它的完整步骤和资源。

④
照手册执行，交付结果

按步骤操作，输出符合规范的结果。

关键词：按需加载——不是把所有技能塞进脑子，而是要用哪本翻哪本。
效果对比

有 Skill 和没 Skill，差别在哪？

没有 Skill

每次重新描述需求，说法稍有不同，结果就变样；

步骤靠 AI 自由发挥，容易漏环节；

好用的做法留在聊天记录里，下次换对话就丢了。

装上 Skill

一句话触发，格式与流程稳定复现；

步骤写进手册，不遗漏、不易错；

经验沉淀成资产，团队里人人可复用。

一句话：Skill 不让 AI"变更聪明"，而是让它"把事做得更稳"。

真实案例

刚才我们亲手用过一次

还记得今天的"创建课程仓库"吗？装环境、配 Git、clone、push 一整套流程，下次再做就是一遍 skill 的活儿。

如果不做成 skill：三个月后你得重新问一遍"怎么配置 SSH 密钥来着？"

如果做成 skill（比如叫 git-course-setup）：下次只需说"帮新班级做一次 Git 环境配置"，AI 自动按今天的完整步骤执行。

教师场景

按固定模板出练习题、批量批改点评、生成家长会简报。

学生场景

按规范格式整理错题本、自动检查代码并提交作业仓库。
